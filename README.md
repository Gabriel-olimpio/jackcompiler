# JackCompiler

Projeto desenvolvido para a disciplina de Compiladores.

O objetivo é implementar progressivamente um compilador para a linguagem Jack, seguindo a abordagem do  nand2tetris.

- [ ] Analisador léxico

- [ ] Compilador
